02 / CASO DE ESTUDIO

Presupuestar una organización,
no cuatro silos.

Caso hipotético · La Paz

Una empresa de servicios digitales planifica los presupuestos trimestrales de sus cuatro unidades. Desarrollo depende de la infraestructura; seguridad acompaña a desarrollo; soporte sostiene la continuidad del servicio. Se busca equilibrar metas financieras y coordinación entre áreas.

Del proceso al modelo

Finanzas define metas t; responsables de área acuerdan rigidez w; el comité revisa dependencias; el simulador calcula; tesorería valida disponibilidad y autoriza desembolsos. La salida es una propuesta, no una transferencia automática.

Flujo financiero: ingresos de clientes → tesorería → presupuestos de las cuatro unidades → pagos de personal y proveedores → seguimiento trimestral. Los acoplamientos representan coordinación de gasto; no son transferencias monetarias entre departamentos.

Reglas de negocio: valores no negativos, revisión de fondos disponibles y protección de compromisos críticos. El caso usa un fondo de referencia de 160 mil Bs; la página señala excedentes sin recortar la solución numérica.

Objetivo financiero

min J(x) = ½ Σ wᵢ(xᵢ − tᵢ)²
+ ½ c Σ (xᵢ − xᵢ₊₁)²

Primera suma: i = 1…4. Segunda: i = 1…3. Cada xᵢ y tᵢ se expresa en miles de bolivianos por trimestre. J es una penalización de planificación, no beneficio ni flujo de caja. wᵢ y c ponderan desviaciones cuadráticas.

La coordinación c = 0,5 favorece presupuestos próximos en unidades conectadas; es una simplificación pedagógica que debe calibrarse si las escalas operativas reales difieren.

Derivación, coeficientes y demostración formal

Al imponer ∇J(x) = 0 se obtiene Ax = b, con A = diag(w) + cL, donde L es el laplaciano de la cadena 1–2–3–4 y bᵢ = wᵢtᵢ. A tiene diagonal [w₁+c, w₂+2c, w₃+2c, w₄+c] y aᵢ,ᵢ₊₁ = aᵢ₊₁,ᵢ = −c; los otros elementos son cero.

vᵀAv = Σ wᵢvᵢ² + c Σ (vᵢ − vᵢ₊₁)² > 0 para v ≠ 0

En los tres escenarios wᵢ > 0 y c = 0,5 ≥ 0. Por tanto A es simétrica y definida positiva y J tiene un único minimizador. Los menores principales positivos calculados por Cholesky verifican también el criterio de Sylvester. Para matrices editadas, se comprueba simetría y factorización de Cholesky; la interpretación de negocio original puede dejar de ser válida.

Procedencia: todos los presupuestos, metas y ponderaciones son supuestos académicos propios; no provienen de una empresa real. Ideal: w = [2,3,2,3], t = [40,55,30,25]. Estrés: igual w, t = [35,42,30,20]. Mal condicionado: w = [1,100,10000,1000000], metas ideales. Las penalizaciones extremas representan rigidez contractual deliberadamente exagerada para estudiar estabilidad, no estimaciones del mercado boliviano.

05 / TRAZABILIDAD MATEMÁTICA

Cada iteración tiene una explicación.

Solución numérica de referencia

Se factoriza A = LLᵀ mediante Cholesky. Primero se resuelve Ly = b por sustitución hacia adelante; luego Lᵀx = y hacia atrás. La referencia utiliza aritmética de punto flotante: no se presenta como solución exacta simbólica.

Lᵢᵢ = √(aᵢᵢ − Σ Lᵢₖ²)
Lᵢⱼ = (aᵢⱼ − Σ LᵢₖLⱼₖ) / Lⱼⱼ

Las sumas se toman sobre los índices anteriores a la columna calculada. La matriz L y el residuo de referencia se muestran en el simulador.

GCP y contraste GC

r₀ = b − Ax₀; Mz₀ = r₀; p₀ = z₀
αₖ = (rₖᵀzₖ)/(pₖᵀApₖ)
xₖ₊₁ = xₖ + αₖpₖ
rₖ₊₁ = rₖ − αₖApₖ
Mzₖ₊₁ = rₖ₊₁
βₖ = (rₖ₊₁ᵀzₖ₊₁)/(rₖᵀzₖ)
pₖ₊₁ = zₖ₊₁ + βₖpₖ

Parada: ‖b − Axₖ‖₂ / ‖b‖₂ < ε, o Nmáx. Se verifica el residuo verdadero después de cada paso. GC usa M = I; Jacobi aplica zᵢ = rᵢ/aᵢᵢ sin invertir una matriz completa. Si b = 0 se usa residuo absoluto, expresamente identificado.

Normas, error y relación con Suñagua (2020)

Eaᵢ = |xref,ᵢ − xGCP,ᵢ|; Erᵢ = Eaᵢ/|xref,ᵢ|; Epᵢ = 100 Erᵢ. Cuando xref,ᵢ = 0, Er y Ep se muestran como no definidos.

Se usa la norma infinito inducida para ambos números de condición: κ∞(B) = ‖B‖∞ ‖B⁻¹‖∞, con ‖B‖∞ = maxᵢ Σⱼ |bᵢⱼ|. La inversa se calcula por Gauss-Jordan con pivoteo parcial. B es A o M⁻¹A. Esta última puede ser no simétrica; no se confunde su número de condición con un cociente de autovalores.

El artículo explica el cambio simétrico C A Cᵀ. Aquí C = M⁻¹/² para Jacobi. La implementación utiliza la formulación equivalente con Mz = r en las variables originales. La notación M de la interfaz corresponde al precondicionador de la consigna, no a la matriz transformada denominada M en parte del artículo.

En aritmética exacta GC converge en a lo sumo n pasos; el redondeo y la pérdida de conjugación pueden requerir más. Menos iteraciones no garantiza menor tiempo total en un sistema pequeño de cuatro variables. No se afirma una aceleración temporal medida.

04 / GOBERNANZA

El modelo apoya al comité

El valor está en coordinar dependencias y hacer explícitas prioridades. El modelo no impone restricciones duras de caja ni mínimos contractuales: si son obligatorios, se necesita optimización restringida.

Guía de uso y recomendaciones

1. Carga un escenario y observa sus supuestos. 2. Revisa matriz, metas y configuración. 3. Modifica A o b; el cálculo se actualiza automáticamente. 4. Compara referencia, errores e iteraciones. 5. Ejecuta QA y revisa el saldo del fondo. 6. Registra tu nombre e imprime si necesitas una copia.

Calibrar las ponderaciones con responsables financieros; validar contratos y disponibilidad antes de aprobar recursos; conservar un registro de supuestos y revisar trimestralmente el modelo. Una matriz editada puede ser válida numéricamente y carecer de sentido organizacional.
